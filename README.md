# Frontend Mentor - Product Preview Card Component

A responsive product preview card built as a solution to the [Frontend Mentor](https://www.frontendmentor.io/) challenge.

## Built With

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Responsive Design
* CSS Variables
* `<picture>` element
* Google Fonts

## Features

* Responsive product card for desktop and mobile screens
* Different product images for desktop and mobile
* Responsive layout using CSS Grid
* Flexible content layout using Flexbox
* Hover and focus-visible states for the button
* Custom fonts using Google Fonts
* CSS variables for colors and typography

## What I Learned

While building this project, I practiced:

* Creating responsive layouts with CSS Grid
* Using the `<picture>` element and `<source>` for responsive images
* Working with `width: 100%` and `height: auto`
* Using `object-fit: cover` when controlling image dimensions
* Creating hover and keyboard focus states
* Working with CSS custom properties
* Using different fonts for headings and body text
* Structuring classes using the BEM methodology
